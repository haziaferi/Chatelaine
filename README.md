# Chatelaine

A home inventory for Android that keeps stored things in view, so what is in a closed box stays present in mind.

Status: planning. No code yet.

How changes land: through a pull request whose CI check (`publish-check`) passes, merged with a merge commit (never squashed or rebased) on the owner's go-ahead; nothing is pushed straight to `main`; no version tags.
